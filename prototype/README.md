# 知识星图 · 交互原型 v1.0（本地编辑 + 只读发布）

视觉统一成 **Obsidian Light**：白底、浅灰侧栏/标签栏、紫色强调色、细边框；保留黄金比例星图卡片。界面按 Obsidian 桌面端组织：左侧功能条 + 文件树，中间标签页 + 编辑器/图谱，右侧大纲/反向链接，底部状态栏。**打开网站默认进入空工作区（无标签）**，从左侧文件树、空工作区按钮或 Ribbon 开始。功能上参考 Obsidian 的核心工作流（双向链接、反向链接、命令面板、快速切换、大纲、图谱）；当前是浏览器原型，不是 Obsidian 插件，也不会直接读取桌面 Obsidian vault。

- **Obsidian 式工作区**：左侧功能条（ribbon）+ 文件树；中间顶部标签页；笔记编辑器与「知识网络」图谱各占一个标签；右侧大纲/反链/出链；底部状态栏。
- **默认空工作区**：打开网站不自动打开星图或笔记，先显示「没有打开的标签」起始页，可新建笔记、打开知识网络或快速切换。
- **图谱入口**：左侧文件树顶部常驻「知识网络」行（带笔记数），空工作区也有「打开知识网络」按钮；Ribbon 图谱图标和命令面板同样可以打开。
- **标签页**：点文件会在中间新开标签，已打开则切回；点 `×` 或 `Ctrl/Cmd+W` 关闭；点「知识网络」标签回到 3D 图谱。「知识网络」本身也是普通标签，可以关闭收起，再从左侧 Ribbon 的图谱图标或空工作区按钮重新打开；所有标签都关闭时显示 Obsidian 式空工作区。
- **Obsidian Light 主题**：白色主背景、浅灰侧栏/标签栏、紫色强调色、细边框；标签活动态为白底并带紫色下划线。
- **弹性图谱/数据布局**：宽屏时图谱占主区、数据卡在右侧栏；≤1099px 图谱全宽、数据卡下移；手机端图谱全宽加高、数据卡单列。使用 `100dvh` 适配 Android 地址栏，右侧大纲在窄屏自动收起。
- **2D 图谱兜底**：如果浏览器 WebGL 被禁用/不可用（远程桌面、关闭硬件加速、企业策略等），自动切换为 Canvas 2D 知识网络，节点可点击打开笔记/分类，数据卡和文件树不受影响；浏览器开启 WebGL 时仍使用 3D 星图。
- **Markdown 源码 + 实时预览**：笔记页右上 `M↓`（或 `Ctrl/Cmd+Shift+M`）进入源码模式，左侧 Markdown 文本、右侧实时预览；编辑会同步回富文本内容，退出时正常保存，阅读/切换标签/关闭标签都会先处理源码。
- **PWA 安装 / 离线**：`manifest.webmanifest` + Service Worker；Android Chrome「添加到主屏幕」、Windows Edge/Chrome「安装应用」后独立窗口运行；断网刷新仍能打开应用（数据仍在 localStorage）；状态栏显示在线/离线。
- **GitHub Pages 部署**：`.github/workflows/pages.yml` 会把 `prototype/` 作为站点根目录发布；步骤见仓库根目录 [DEPLOY.md](../DEPLOY.md)。
- **本地编辑 / 线上只读**：`file://` 和 `localhost` 可编辑；非 localhost 域名（GitHub Pages）自动只读。线上读取 `published-vault.js` 快照，访客不写 localStorage。左侧 `⋯` →「导出发布快照」生成该文件；命令面板可「预览访客只读页」。
- **Markdown 互通**：左下 `⋯` 或命令面板可「导出 Obsidian Vault（.zip）」——按分类生成文件夹，每篇笔记带 `title/category/tags/updated` frontmatter，双链保持 `[[标题]]`；也支持「导入 Markdown 笔记」（多选 `.md`，读取 frontmatter/标题/标签/分类，支持标题、列表、引用、代码块、表格、双链）和导出当前笔记 `.md`。
- **知识点独立页面**：点左侧文件或星图节点，跳转到 `#/note/<知识点 id>` 的独立标签页，不再弹右侧抽屉。
- **新建不弹窗**：选中一级分类后点「新建」，直接在该分类下生成空白文件并打开页面，标题输入框自动聚焦、全选，直接输入就是重命名。
- **没有选中一级分类时**：点「新建」会新建一个一级分类（默认名「新分类」），并在里面生成空白文件；分类名可双击重命名。
- **分类可删除**：每个一级分类右侧有 `×`；删除会二次确认，并连同该分类下的知识点和版本历史一起删除。
- **树可以自由展开/收起**：点击一级分类切换展开状态，再点就收起；一级分类下直接放知识点文件，原二级主题已取消。
- **左侧分类栏整体收起/展开**：分类栏右上角 `«` 收起，收起后主面板左上角 `»` 展开；主面板会跟着变宽。
- **两栏独立滚动**：分类树的上下滚动和主面板（星图/数据卡/工作区）的上下滚动分开控制，互不带动。
- **滚动与 3D 操作分开**：鼠标在 3D 图内时，滚轮只缩放图、不滚主面板；鼠标移到图外（数据卡/工作区）滚轮才滚主面板。3D 图内触摸拖动只旋转图，不带动面板滚动。
- **删除掌握度与复习**：知识点内容、树、数据卡片里都不再有掌握度；复习卡片和复习弹窗整体删除。数据区只剩「最近更新」和「数据概览」两块。
- **黄金比例**：星图、最近更新、数据概览都是 1.618:1 的黄金比例卡片。
- **圆形节点 + 名称内嵌**：3D 图节点改成圆形节点，名称直接写在节点圆里；一级分类稍大，关键知识点次之，普通知识点更小。圆形节点层不拦截指针，从节点上直接拖动也能旋转 3D 图；点击节点仍然打开知识点。
- **分类互通**：分类节点之间增加一条主干连线；新建分类会自动接到主干上，不会出现孤立的新分类。
- **连线与背景**：根节点到文件、知识点、分类主干之间的连线加粗提亮；浅色主题下星图使用浅灰画布、淡紫/淡蓝星云和深色节点文字。
- **星图不跟树联动**：点击分类/文件不会过滤、缩放或改变星图；星图始终展示完整节点集合。新增/删除文件时星图实时增减节点。
- **旋转与流畅度**：相机由每帧手动旋转驱动（3d-force-graph 自带 autoRotate 在引擎冷却后会停）；圆形节点位置也每帧更新；节点悬停不再有缩放/高亮动画，也不打断旋转。只有鼠标在 3D 图内拖拽/滚轮时才接管视角，图外的鼠标移动、点击、滚轮都不影响旋转。进入知识点页面暂停渲染，返回时恢复。
- **双向链接**：正文里写 `[[HTTP 与 HTTPS]]`（或工具栏 `[[ ]]`）会变成可点击双链；点击跳到目标笔记，目标不存在时会自动创建。双链会自动变成 3D 图里的连线。
- **反向链接 / 出链**：知识点页面右侧新增 Obsidian 风格检查器：大纲、反向链接、出链；反向链接列出所有链入当前笔记的来源。
- **命令面板**：`Ctrl/Cmd + P` 打开命令面板，可新建笔记/分类、搜索、收起分类栏、暂停旋转、导出备份等；`Ctrl/Cmd + O` 按标题快速切换笔记。
- **阅读视图**：`Ctrl/Cmd + E` 在编辑/阅读之间切换；阅读视图隐藏工具栏、锁定标题与属性，只保留内容和右侧大纲/反链。
- **版本历史**：每次打开知识点会记录一个初始版本；之后自动保存时按 8 秒合并记录（最多 40 个），可在页面底部「历史」里查看时间、标题、分类和内容摘要，并一键恢复。

## 打开方式

1. **推荐：直接双击** `index.html`；3D 库在 `vendor/`，不需要联网，也不需要后台。直接双击时 PWA 安装/离线不可用。
2. 想在浏览器里用 `http://` 访问时，在本目录启动静态服务：
   ```bash
   python -m http.server 8765
   ```
   然后打开 http://127.0.0.1:8765/ 。`localhost` 下可以测试 Service Worker、安装和离线。
   > 8765 是临时本地预览服务，会话/环境重启后会停止；打不开时先用方式 1。
3. 需要支持 WebGL 的现代浏览器（Edge / Chrome / Safari）；没有 WebGL 会自动使用 2D 图谱。
4. GitHub Pages 发布：见 [DEPLOY.md](../DEPLOY.md)。

## 怎么用

1. **左栏文件树**：每行是一级分类，点一下展开并选中，再点收起；文件直接列在分类下面。文件树可以单独上下滚动。左侧功能条 `«` 可整体收起分类栏，左上角 `»` 展开。
2. **打开知识点**：点左栏文件，或点星图节点；会在顶部新开标签页。关闭标签或点「知识网络」标签回到图谱。
   图谱标签可以关闭收起：点标签 `×`、`Ctrl/Cmd+W`，或图谱右上角 `—`；左侧 Ribbon 图谱按钮可重新打开。关掉全部标签会进入空工作区，可新建笔记、打开知识网络或快速切换。
3. **重命名文件 / 写双链**：进入页面后直接改标题输入框；停止输入约 0.7 秒自动保存。正文输入 `[[笔记标题]]`，失焦后变成可点击双链；工具栏 `[[ ]]` 也可以插入。
4. **右侧检查器**：大纲可跳转到正文标题；「反向链接」列出链入当前笔记的页面；「出链」列出当前笔记链接到的页面，缺失的点击会创建。
5. **新建**：
   - 先点一个一级分类 → 点左下「新建」：在该分类下生成「未命名知识点」；
   - 点顶部「全部知识点」清空选择 → 点「新建」：新建一个一级分类，并在里面生成空白文件。
   - 新建后标题输入框自动聚焦、全选，直接输入即可重命名。
6. **分类重命名 / 删除**：双击一级分类名字内联重命名；点右侧 `×` 删除分类（会同时删除其中文件和版本历史，需确认）。
7. **命令面板 / 快速切换 / 阅读 / 源码**：`Ctrl/Cmd+P` 命令面板，`Ctrl/Cmd+O` 按标题切换笔记，`Ctrl/Cmd+W` 关闭当前标签，`Ctrl/Cmd+E` 切换阅读视图，`Ctrl/Cmd+Shift+M` 切换 Markdown 源码与实时预览。
8. **星图**：1.618:1 黄金比例卡片；节点是带名称的圆形节点；默认缓慢自动旋转（自定义相机驱动），悬停节点不改变节点样式也不暂停旋转；从节点上也可以直接按住拖动旋转 3D 图；图内滚轮只缩放图，不滚主面板；图外滚轮才滚主面板。点击分类节点会展开对应分类，点击知识点节点进入独立页面。
9. **搜索**：搜索框或按 `K`；结果点击直接进入知识点页面。搜索只高亮星图，不隐藏节点。
10. **版本历史**：知识点页面底部「历史 N」→ 选中任意版本「恢复」；恢复前会把当前状态先记成一个版本。
11. **备份**：左下 `⋯` →「导出备份」会下载包含知识点和版本历史的 JSON；「导入备份」用同一格式覆盖当前数据。换浏览器/设备时用这个迁移。
12. **删除**：在知识点页面底部「删除」；删除后星图节点和数据同步减少，该文件的版本历史也会删除。

## 数据与限制

- 假数据，无后端；改动保存在当前浏览器的 `localStorage`，换浏览器/设备不同步。
- 分类是一层：**一级分类 → 知识点文件**。如果你后面还想要两级，需要恢复分类层级和树逻辑。
- 新建时如果没有选中一级分类，会新建一级分类；这是当前规则，不是 bug。
- 编辑器默认是 contenteditable 富文本；Markdown 源码/预览是转换层，内部存储仍是 HTML，不是把 vault 改成 `.md` 文件系统。公式、Mermaid、图片目前是占位插入，未接真正渲染/上传；导入笔记里的相对图片路径不会自动带上附件。
- Markdown 源码模式支持标题、加粗/斜体/删除线、列表、引用、代码块、表格、链接、图片和 `[[双链]]`；Obsidian 的 callout、嵌入 `![[...]]`、frontmatter 编辑等尚未完整支持。
- 双链是按**标题**解析的，同名知识点会优先匹配第一个；不是完整 Markdown/Obsidian vault 实现，也没有 `.md` 文件读写和实际 Obsidian 插件接入。
- 主题/布局模仿 Obsidian，但 3D 知识网络是本项目自己的视图，不是 Obsidian 的 2D Graph View。
- 版本历史也只存在当前浏览器的 localStorage，最多每个知识点 40 个；换设备不会同步，删除文件会一起删除历史。
- 「导出备份」是 JSON；导入会覆盖当前数据，请先导出再导入。
- 单人、单设备编辑；手机端可用，桌面优先。
- PWA 只缓存应用外壳和发布快照；本地编辑数据仍在本机 localStorage，换域名/设备不会同步。
- 只读是纯静态发布快照方案：访客不能改线上内容，但源码和 `published-vault.js` 都是公开的；不是账号级鉴权。真正的 GitHub 登录编辑 / 私有内容需要 OAuth + 后端或 Serverless。
- 部署前先「导出发布快照」替换 `published-vault.js`，否则线上只读站显示示例数据。
